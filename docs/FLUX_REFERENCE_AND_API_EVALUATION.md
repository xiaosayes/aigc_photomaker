# 风格参考图与第三方 API 评估

> 本文是评估，不代表已经实现风格参考图上传或第三方 API 接入。

## 1. 人物图 + 每种风格一张参考图能否实现

### PhotoMaker 路线

当前 PhotoMaker Encode 只负责身份编码，不能把第二张图片自动当作风格条件。若要增加风格参考图，需要额外 IP-Adapter/风格编码器、风格 LoRA 或独立风格迁移步骤。只增加一个文件上传控件并不能实现风格控制，还会引入身份与风格权重分配、显存和兼容性问题。

### InstantID 路线

InstantID 负责身份与关键点，风格参考同样需要额外 IP-Adapter 或专用风格路径。cubiq 生态存在 InstantID + IP-Adapter 的组合示例，但这属于另一套模型与工作流，需要新权重、新节点和独立 A/B，不是当前 InstantID 节点的原生第二图片参数。

### FLUX.2 [klein] 路线

FLUX.2 [klein] 原生支持多参考图编辑，因此在三种路线中最适合“人物身份图 + 风格参考图”。但仍须新增完整产品逻辑：

- 身份输入与风格输入分开，风格参考不强制单人脸；
- 每种风格配置一份经过授权和人工验收的参考素材；
- 在图和提示词中明确哪个参考负责身份、哪个负责风格；
- 增加多参考 VAE/ReferenceLatent 工作流和输入顺序测试；
- 评估参考人物是否把额外人脸带入输出，输出守卫仍要求单人；
- 保存素材来源、许可、版本和 hash，不上传用户私人参考图到仓库。

因此它是**可行的新功能**，不是当前单参考工作流已经默认具备的能力。

## 2. 第三方商用 API 是否可以直接替代本地部署

可以接入，但不是把本地 ComfyUI URL 替换为 API 地址就结束。仍需实现供应商鉴权、请求映射、任务轮询/下载、限流、错误处理、费用记录、内容政策、数据授权和验收。

| 场景 | 可行性 | 主要条件 |
| --- | --- | --- |
| 无参考图，仅文本风格化 | 最容易 | 供应商支持文本生图与目标风格，内容政策允许 |
| 一张人物身份参考图 | 取决于具体模型 | 必须支持图像编辑/图生图，并能保持身份；普通文本 API 不够 |
| 人物图 + 风格参考图 | 取决于多图能力 | 需要一次请求接收多图并区分角色，或拆成两次调用 |

多图 API 也可能把“风格参考中的人物”与“身份人物”混淆。若供应商不能明确区分角色，可采用两步法：先从风格参考提取色彩/材质/构图描述，再把该描述与人物图一起请求编辑。两步法兼容性更好，但增加时延和费用。

## 3. 本地与 API 对比

| 维度 | 本地 FLUX.2 | 第三方商用 API |
| --- | --- | --- |
| 风格效果 | 可用 ReferenceLatent 和专用工作流细调，受本地模型/素材限制 | 可能直接获得较强通用风格，但无法保证每种风格都可定制 |
| 身份保持 | 可调整参考条件并做 A/B，控制力强 | 取决于供应商模型，难以逐层调参，版本升级可能改变结果 |
| 多参考图 | 原生多参考是优势，但需自行设计角色和验证 | 只有部分模型支持，角色理解不一定稳定 |
| 时延 | 预热后稳定，受 3090、权重切换和队列影响 | 无需维护 GPU，但含上传、排队、生成和下载，P95 随网络与平台负载波动 |
| 成本 | 已有硬件时主要是电费和运维，新增权重大但一次投入 | 按张/令牌/分辨率计费，多图和多步调用费用更高 |
| 隐私 | 图片留在本地，最易控制保留期 | 图片离开服务器，须核对保存、训练使用、删除和跨境条款并取得授权 |
| 运维 | 需维护模型、节点、显存和兼容性 | 无需模型运维，但需处理密钥、配额、供应商故障和版本变更 |
| 可复现性 | 可固定权重、节点、seed 和离线环境 | 受供应商模型版本与内部策略影响，完全复现较难 |
| 离线能力 | 可在断网环境运行 | 无网络即不可用 |

## 4. 推荐决策

- **敏感人脸、需要离线或精细控制**：优先本地 FLUX.2，并另行设计多参考风格输入。
- **非敏感测试、希望快速获得效果上限**：可用商用 API 做文本与图像编辑对照，记录真实 P50/P95、费用和失败率，不把一次好图当作长期稳定性。
- **人物图 + 风格图**：优先选明确支持多参考角色区分的 API；不支持时用两步法，不要假定所有图像 API 都支持。
- **生产选择前**：用同一批授权人物、同一风格素材和同一 seed/提示词，分别比较本地与 API 的身份、风格、额外人脸、P95 时延、单张成本、隐私和失败恢复。

第三方 API 是另一种交付方案，不是本地模型功能的等价替代品。是否更好必须由同一样本集的实测决定。
