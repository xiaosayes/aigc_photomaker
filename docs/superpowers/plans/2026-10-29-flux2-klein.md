# FLUX.2 [klein] 4B 人脸风格化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `feature/flux` 上交付完整 FLUX.2 Base Standard 与 Distilled Turbo 单人照片风格化功能，不合并到 `main`。

**Architecture:** 保留现有 API/Worker/SQLite/前端，替换为 FLUX.2 UNET/Qwen/VAE、原生 ReferenceLatent 身份条件和自定义高级采样。antelopev2 只做输入/输出单人脸检查。第一版不加载 SDXL LoRA 或 InstantID 身份模型。

**Tech Stack:** Python 3.11、ComfyUI 0.42.1、FLUX.2 [klein] FP8、ReferenceLatent、FastAPI、SQLite、pytest。

## Global Constraints

- 只修改 `feature/flux`，不合并到 `main`。
- Standard：Base FP8、20 步、CFG 4.0；Turbo：Distilled FP8、4 步、CFG 1.0；均为 1024×1024、batch 1、euler。
- 输入/输出均须单人脸；保持物理 GPU 1 和单活跃任务。
- 本地只做静态检查，服务器执行 pytest、模型下载和真实出图。
- 新模型按已批准 revision/size/SHA256 锁定；不上传 `.env`、数据、模型或报告。
